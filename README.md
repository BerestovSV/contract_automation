# Генератор договоров B2B

## Установка

1. Скачайте папку `ContractGenerator`
2. Запустите `build.bat` (только при первом использовании)
3. Исполняемый файл находится в папке `dist/ContractGenerator.exe`

## Использование

1. Запустите `ContractGenerator.exe`
2. Нажмите "Выбрать шаблон" и выберите файл шаблона договора
3. Нажмите "Выбрать карточку" и выберите Excel-файл с данными компании
4. Проверьте данные компании в окне приложения
5. При необходимости измените номер договора
6. Нажмите "Сгенерировать договор"

## Структура файлов

- `templates/` - папка для шаблонов договоров (.docx)
- `data/` - папка для карточек компаний (.xlsx)
- `output/` - папка для готовых договоров

## Требования

- Windows 7 или выше
- Microsoft Word (для просмотра результатов)

## Решение проблем

Если приложение не запускается:
1. Проверьте, что в папке `templates` есть шаблоны
2. Проверьте, что в папке `data` есть файлы карточек
3. Попробуйте запустить от имени администратора
