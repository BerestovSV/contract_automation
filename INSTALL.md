# Установка «Генератора договоров B2B»

Два способа: готовый EXE (для сотрудников) и запуск из исходников
(для разработки и сборки).

---

## Вариант 1. Готовый EXE (рекомендуется для пользователей)

Ничего устанавливать не нужно — ни Python, ни библиотеки.

1. Получите файл `ContractGenerator.exe` (из папки `dist` после сборки или из
   артефакта сборки GitHub Actions).
2. Скопируйте его в любую папку, где у вас есть права на запись,
   например `C:\Users\<Вы>\Desktop`.
3. Запустите двойным щелчком.

При первом запуске Windows SmartScreen может показать предупреждение
(приложение не подписано цифровой подписью). Нажмите
**«Подробнее» → «Выполнить в любом случае»**.

Права администратора не требуются.

### Что создаётся при первом запуске

| Что | Где |
|-----|-----|
| Настройки | `%LOCALAPPDATA%\ContractGenerator\settings.json` |
| Журнал | `%LOCALAPPDATA%\ContractGenerator\logs\contract_generator.log` |

База данных договоров (`contracts.sqlite3`) **не создаётся**: приложение не
ведёт реестр выпущенных договоров.

Готовые договоры сохраняются в выбранную вами папку (по умолчанию
`Документы\ContractGenerator`). Папки `templates`, `data` и `output` рядом с
EXE не нужны.

### Порядок работы

1. **Шаблон договора** — «Обзор…», выберите `.docx`.
2. **Карточка компании** — «Обзор…», выберите `.xlsx`.
3. **Папка для результата** — «Обзор…» (запоминается).
4. Проверьте таблицу реквизитов. Столбец «Статус»:
   * `OK` — значение заполнено и прошло проверку;
   * `ОШИБКА` — генерация заблокирована, поле нужно исправить;
   * `ВНИМАНИЕ` — генерация возможна после подтверждения;
   * `АВТО` — значение определено программой, проверьте и подтвердите его;
   * `нет данных` — поле пустое и необязательное.
   Любое значение можно исправить прямо в таблице.
5. Введите **номер договора вручную** в поле «Номер договора» под таблицей.
   Это единственное поле для номера; в таблице реквизитов его нет.
   Автоматической генерации номеров нет, и приложение не проверяет,
   использовался ли такой номер раньше. Номер обязателен всегда — как и
   наименование компании и дата договора.
6. Нажмите «Проверить данные» — под таблицей появится отчёт на русском.
7. Нажмите «Сгенерировать договор». Кнопка неактивна, пока есть ошибки;
   перед созданием файла проверка выполняется заново.
   Договор не будет создан, если хотя бы один плейсхолдер `{...}` шаблона
   неизвестен приложению или остался без значения.
8. «Открыть документ» или «Открыть папку» — для просмотра результата.

Исходные шаблон и карточка **не изменяются**.

### Если что-то пошло не так

| Симптом | Что делать |
|---------|-----------|
| «Формат .xls не поддерживается» | Откройте карточку в Excel → «Сохранить как» → «Книга Excel (*.xlsx)» |
| Кнопка генерации неактивна | Посмотрите поля со статусом `ОШИБКА` и отчёт под таблицей |
| «Не удалось записать файл» | Закройте документ в Word и проверьте права на папку |
| «Шаблон заполнен не полностью» | В шаблоне есть `{поле}` без значения; заполните названные в сообщении поля |
| «Неизвестный плейсхолдер» | В шаблоне опечатка (`{contract_namber}`) или поле, которого приложение не знает; исправьте шаблон |
| «Укажите пол явно» | Шаблон использует «действующего/действующей»; заполните поле «Пол подписанта» |
| Приложение не запускается | Откройте `%LOCALAPPDATA%\ContractGenerator\logs\contract_generator.log` |

## Вариант 2. Запуск из исходников

### 1. Python

Установите **Python 3.11** с https://python.org/ (проверено также на 3.14).
При установке отметьте **«Add Python to PATH»**.

Проверка:

```bat
python --version
```

### 2. Окружение и зависимости

Из папки проекта:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

Зависимости ставятся **только внутрь `.venv`**; системный Python не
затрагивается.

### 3. Запуск

```bat
.venv\Scripts\python.exe main.py
```

или двойным щелчком по `launch.bat`.

### 4. Тесты

```bat
.venv\Scripts\python.exe -m pytest
```

### 5. Сборка EXE

```bat
build.bat
```

Скрипт создаёт `.venv` (если его нет), ставит зависимости, прогоняет тесты,
очищает `build` и `dist` и собирает `dist\ContractGenerator.exe`.
При ошибке возвращается ненулевой код завершения.

## Требования

* Windows 10 или новее (64-разрядная).
* Microsoft Word или совместимый редактор — только для просмотра результата;
  для генерации Word не нужен.
* Подключение к интернету не требуется ни на одном этапе работы.
